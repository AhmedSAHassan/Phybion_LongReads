# PhyBioN_LongRead_Analysis
Analysis pipeline for Phybion_LongRead manuscript

## Experimental design

Blood samples from 3 healthy donors (2 males and 1 female) were exposed to X-ray irradiation of 4 Gy, and incubated 6 h post-irradiation. Sham-irradiated (0 Gy) controls were maintained under identical conditions in the control room.

To run the analyses reported in the PhyBioN_LR_Analysis.Rmd notebook, simply open it in an RStudio IDE session or any equivalent tool.
